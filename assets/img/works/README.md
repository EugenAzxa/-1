# Куда класть реальные фотографии

Сайт собран так, что карточки работают и без реальных снимков: пока файла нет,
показывается фирменная заливка с иконкой. Как только вы кладёте файл с нужным
именем в эту папку, он автоматически появляется на месте заливки. Ничего
править в коде не нужно.

Перед загрузкой сожмите кадр примерно до 300 КБ:

```bash
sips -s format jpeg -s formatOptions 72 -Z 1600 исходник.jpg --out assets/img/works/racer.jpg
```

Важно: публикуем детские фотографии только при наличии письменного согласия родителей.
